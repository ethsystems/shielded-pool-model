# Rename map: earlier name -> name here.
#
# The modules were first written with working names. This map gives each earlier module and
# namespace the name it has in this package, so that older reports can be read against these
# files. scripts/rename.py applies it forwards; scripts/check-rename.py applies it backwards to
# check that only names and comments changed.
#
# Kinds: "module" renames a module in import lines (and the file path); "namespace" renames a
# namespace wherever it starts an identifier, as a whole name (full dotted forms are listed
# separately, because the substitution does not match after a "."); "control" documents the
# earlier name of a control file and is not applied. Declaration names do not change, and the
# declarations keep the namespace LeanShieldedPool.Refine.
