# shielded-pool-model

A small Lean 4 model of spec 2/SHIELDED-POOL with machine-checked proofs
that no note spends twice and that value is conserved per token, made for
review. The model is the open pull request from branch `model-v1`: read
its commits in order, its README first. Until it merges, this branch
holds only the Lean toolchain and build files.
