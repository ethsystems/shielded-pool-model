# Rename map: old name -> new name.
#
# The game modules were first written with working names: a game number per experiment and
# one flat module directory. This map gives each old module and namespace the name it has in
# this package, so that older reports can be read against these files. scripts/rename.py
# applies it: "module" entries on import lines (and to the file path), "namespace" entries as
# whole name components everywhere else. scripts/check-rename.py applies it backwards and
# checks that only names and comments changed. The audit modules of the first form
# (`#print axioms` lists) are not here; the census replaces them.
