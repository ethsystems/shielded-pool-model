# Trait interfaces the mirrors take as parameters

Generated by `scripts/coverage.py --write`; each block is copied verbatim from the mirror. A `spec fn` is an abstract function with no body: the proofs assume nothing about its value. An executable method states its result through its `ensures` clause, and the proofs take that clause as given: these clauses are the trusted contracts. No implementation of any trait is given or checked here; that the real library (alloy, ruint, arkworks, light-poseidon, k256, sealring, serde, toml, tokio, lean-imt, the file system and the prover processes) meets its contract is assumed.

## `crypto_field.rs`: `PoseidonHasher`

```rust
pub trait PoseidonHasher: Sized {
    spec fn nr_inputs(&self) -> nat;
    spec fn h1(a: nat) -> nat;
    spec fn h2(a: nat, b: nat) -> nat;
    spec fn h4(a: nat, b: nat, c: nat, d: nat) -> nat;
    fn new_circom(nr_inputs: usize) -> (r: Result<Self, PoseidonError>)
        ensures 1 <= nr_inputs <= 12 ==> (r is Ok && r->Ok_0.nr_inputs() == nr_inputs);
    fn hash(&mut self, inputs: &[Fr]) -> (r: Result<Fr, PoseidonError>)
        ensures
            inputs.len() == old(self).nr_inputs() ==> r is Ok,
            (inputs.len() == old(self).nr_inputs() && inputs.len() == 1) ==>
                r->Ok_0.val() == Self::h1(inputs@[0].val()) % R(),
            (inputs.len() == old(self).nr_inputs() && inputs.len() == 2) ==>
                r->Ok_0.val() == Self::h2(inputs@[0].val(), inputs@[1].val()) % R(),
            (inputs.len() == old(self).nr_inputs() && inputs.len() == 4) ==>
                r->Ok_0.val() == Self::h4(inputs@[0].val(), inputs@[1].val(), inputs@[2].val(), inputs@[3].val()) % R();
}
```
