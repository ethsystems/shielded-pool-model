# Rename map: old name -> new name.
#
# The proof modules were first written with working names. This map gives each old
# module, namespace and helper-function name the new name it has in this package, so
# that older reports can be read against these files. scripts/rename.py applies it as
# a token substitution (whole identifiers, longest first) and scripts/check-rename.py
# applies it backwards to check that only names and comments changed.
#
# Kinds: "module" names a Lean module (and its file), "namespace" a namespace,
# "both" a name used as module and namespace, "prefix" a Noir path prefix of the
# helper functions declared with noir_def, "theorem" a theorem name in a hand-written
# control, "control" a must-fail control, "source" the earlier file name of a hand-written
# control.
